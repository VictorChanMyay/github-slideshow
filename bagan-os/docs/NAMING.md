# Naming

**Working title: Bagan OS** (ပုဂံ). Final decision after the checks below.

## Why Bagan
- Iconic, positive, UNESCO-listed ancient capital known worldwide
- Short and easy to say and type (`bagan-os`, `bagan-desktop`)
- Rich identity: temple skyline, sunrise, hot-air balloons; releases can be named after temples (Ananda, Dhammayangyi, Shwezigon)

## Criteria
- Easy to say and type in Burmese and English
- No political or ethnic-group-specific associations
- No trademark clash
- Domain and GitHub org available

## Open checks
- [ ] Ethnic inclusiveness: the Bagan Kingdom is tied to the Bamar majority; ask Kachin, Shan, Karen, Mon, Rakhine and other communities how the name reads
- [ ] GitHub/GitLab org and repo names
- [ ] distrowatch.com and existing software named Bagan
- [ ] Domains: bagan-os.org, .com, .mm
- [ ] Trademark search (USPTO, EUIPO, Myanmar)
- [ ] Spelling fixed as "Bagan" (not "Pagan")
