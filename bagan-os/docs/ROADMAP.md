# Roadmap

## Stage 0: Foundation (weeks 1-4)
- [ ] Choose a name ([NAMING.md](NAMING.md))
- [ ] Create a dedicated repo and org
- [ ] Form the core team: packager, translator, designer, community lead
- [ ] Confirm base: Debian stable + XFCE

## Stage 1: Remix, v0.1 (months 1-3)
- [ ] Bootable live ISO with Burmese locale (`my_MM.UTF-8`) as default
- [ ] Fonts: Noto Sans Myanmar, Padauk, Myanmar Text-compatible fallback
- [ ] Input: Fcitx5 / iBus with Myanmar layouts (Myanmar3 and a Zawgyi-style layout)
- [ ] Calamares installer with Burmese strings
- [ ] Preinstalled: Firefox, LibreOffice, VLC, text editor, file manager
- [ ] Zawgyi → Unicode converter tool
- [ ] Test on 5+ real machines, including 2 GB RAM / old CPUs

## Stage 2: Localization depth (months 3-6)
- [ ] Translate desktop and apps upstream (Weblate, Launchpad, XFCE i18n)
- [ ] Burmese spellcheck dictionary (Hunspell)
- [ ] Fix Burmese line-breaking and rendering bugs upstream
- [ ] Burmese user guide and video tutorials

## Stage 3: Own identity (months 6-12)
- [ ] Welcome / first-run app in Burmese
- [ ] Curated software center (education, productivity, government forms)
- [ ] Offline package mirror and USB updater
- [ ] Own apt repository and update server
- [ ] Burmese OCR (Tesseract `mya`)

## Stage 4: Community (year 1+)
- [ ] Install-fests at universities, schools, NGOs
- [ ] Funding: donations, NLnet, Open Collective, local sponsors
- [ ] Governance model and code of conduct
- [ ] Stable release cycle (e.g. yearly, with security updates from Debian)
